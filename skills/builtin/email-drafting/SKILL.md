# Email Drafting

1. Determine the recipient relationship, purpose, desired action, tone, deadline, and facts that must remain exact.
2. Ask only for missing information that materially changes the message. Never invent commitments, approvals, dates, prices, or attachments.
3. Lead with the purpose. Put context after the request, and make the next action unmistakable.
4. Prefer short paragraphs and concrete language. Remove filler, defensive wording, and accidental ambiguity.
5. For sensitive or high-stakes messages, identify statements the user should verify before sending.
6. Do not send, publish, or address the message to a real recipient; produce a draft for user review.

Return a subject, body, and a short `Verify before sending` list when needed. Offer one alternate tone only when it would materially help.
