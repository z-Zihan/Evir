# Evidence Mapping

1. Define the decision or report scope and list the material claims it depends on.
2. Record each source with type, location, date/version, owner, directness, and limitations.
3. Link claims to supporting and contradicting evidence. Quote only the minimum needed and preserve source context.
4. Rate confidence using explicit reasons: corroboration, recency, primary/secondary source, completeness, and bias risk.
5. Separate fact, interpretation, estimate, assumption, and unknown. Never turn repeated claims into independent corroboration.
6. Prioritize missing evidence by its ability to change the decision.

Return a claim/evidence matrix, contradictions, confidence rationale, provenance gaps, and the next evidence to collect.
