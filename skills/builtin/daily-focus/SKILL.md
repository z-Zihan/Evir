# Daily Focus

1. Capture available time, fixed commitments, deadlines, energy constraints, dependencies, and the complete candidate list.
2. Select no more than three primary outcomes for the day; this limits the plan, not Skill activation.
3. Order work by urgency, impact, dependency, and cost of delay. Explain one-line tradeoffs for deferred items.
4. Break primary outcomes into the next observable action and a clear done condition.
5. Reserve buffer for interruptions. Do not schedule more work than the available time supports.
6. Add a short shutdown review: completed, moved, blocked, and first action for tomorrow.

Return fixed commitments, primary outcomes, schedule blocks, deferred items, risks, and shutdown checklist.
