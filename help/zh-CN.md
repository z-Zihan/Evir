# Evir 使用帮助

## 快速开始

1. 打开“设置 → 模型供应商”。
2. 选择厂商、协议和模型，填写自己的 API Key。
3. 测试连接后返回主界面。Web 直接使用 Ask；Desktop 通过侧栏开始。
4. 输入消息并发送；流式过程中可随时停止。

## 侧栏：Projects 与 Chats

Desktop 侧栏分为两区：

- **PROJECTS**：一个项目对应一个本地目录。在项目里新建任务（Thread）后，Agent 的工作目录就是项目根目录，不需要再手动选择工作区。项目支持置顶、重命名、排序、搜索；目录被移动或改名后会显示“Folder not found”，按提示重新定位即可，历史任务与权限都会保留。
- **CHATS**：独立聊天，只是对话和分析，永远不会触碰本地文件。

## Ask / Plan / Goal / Agent

- Ask：只聊天和分析，不自主访问本地资源（独立聊天恒为 Ask）。
- Plan：项目任务里的一等模式。只用只读工具检查文件和 Git 状态并产出计划；计划确认后可一键“Execute Plan”转入 Agent 执行。
- Goal：项目任务里的一等模式。面向长期目标，可附带“完成条件”；Evir 会按条件逐步验证，直到证据满足或你叫停。
- Agent：可以按权限规则执行工具、修改文件和运行命令。

模式选择位于项目任务输入框上方的紧凑控制区；模型不支持工具调用时模式会禁用并提示换模型。Web 不显示项目、Agent、Plan、Goal 或 MCP。

## 项目权限（Permission）

每个项目可独立选择权限档位：

- **Ask for Approval**（默认）：项目内的写入与命令逐次审批，只读自动。
- **Workspace Access**：项目内常规读写与命令自动放行，并在审计中留痕。
- **Full Access**：解除目录边界；首次开启必须通过明确的确认对话框。

还可以为项目添加额外授权目录（Additional Access Roots）。

## 个性化

当前设置页可配置称呼、回复语言、详细程度、表达风格和自定义指令。`USER.md`、`PERSONA.md`、`INSTRUCTIONS.md` 与 `SOUL.md` 高级编辑器尚未开放。所有个性化内容都不能覆盖 Evir 安全和权限规则。

## Skill

Skill 描述完成某类任务的方法。可以启用内置 Skill、导入本地 Skill，或通过 Skill Creator 创建。安装第三方 Skill 前检查它需要的能力和工具。

## MCP（Desktop）

MCP 用于为 Evir 提供外部工具和资源。Desktop 支持本地 stdio 与远程 Streamable HTTP 服务器：在“设置 → MCP”保存配置并启用后，Evir 会真实连接、发现工具；新服务器默认禁用，工具调用仍受权限系统管控。若连接失败，配置页会显示明确错误而不是假装已连接。

## 权限和网络

文件写入、终端命令、删除、发布和上传本地内容具有不同风险。网络访问与上传本地数据是两个独立权限。重要操作会要求确认。

## 通知

系统通知能力尚未在当前设置界面开放，也不会在首次启动时请求通知权限。

## 快捷键

使用 `Cmd/Ctrl+N` 新建会话，`Cmd/Ctrl+,` 打开设置，`Cmd/Ctrl+/` 查看快捷键，`Esc` 停止当前生成或关闭最上层弹窗。当前可用列表位于“设置 → 快捷键”；命令面板与快捷键自定义尚未开放。

## Token 与用量

用量页可按时间、供应商和模型查看 Token、请求数和响应性能。供应商返回的数据标记为准确值，本地 tokenizer 计算的数据标记为估算值。

## 数据与隐私

Evir 数据默认留在本地。API Key 存入系统安全凭据库。隐私会话不会写入长期聊天、记忆和用量记录，但模型请求仍受所选供应商的数据政策约束。

## 故障排查

- Web 无法连接但 Key 正确：检查 CORS，或改用 Desktop。
- Agent 模式不可用：检查模型是否支持 Tool Calling。
- MCP：连接失败时查看配置页错误信息；启用配置后仍需连接成功才能调用工具。
- 响应中断：保留已生成内容后重试，并检查供应商状态页。

## 提交反馈

当前应用内尚无反馈表单。可手动前往项目 GitHub Issues 提交问题；不要提交 API Key、私密对话或敏感文件内容。

## 切换模型

空闲时可直接切换。正在生成时默认下一条消息生效；也可先停止。Agent 正在执行工具时，Evir 会等待安全步骤边界并生成任务交接摘要；运行中的任务始终绑定它开始时的项目目录，切换侧栏项目不会影响它。跨供应商切换会提示后续数据将发送到新的服务。

## 上下文压缩

Evir 会在长会话接近模型上下文上限时自动整理旧对话和工具输出。用户要求、权限、当前任务、文件变更和验证结果会优先保留。默认不要求额外配置一个压缩模型。

## 日志与诊断

“设置 → 诊断”可查看脱敏运行事件并导出 JSON（全端）。Desktop 还会将日志分类持久化到本地文件，并支持**导出诊断包 (ZIP)**：导出前会预览文件数与体积，包内含系统/供应商/MCP 元数据与本地日志，全部经过脱敏，绝不包含 API Key 或会话正文。诊断包由你手动保存并发送，Evir 没有任何远程读取日志的后门。
