# Evir 使用帮助

## 快速开始

1. 打开“设置 → 模型供应商”。
2. 选择厂商、协议和模型，填写自己的 API Key。
3. 测试连接后返回聊天页。Web 直接使用 Ask；Desktop 默认 Agent，也可切换 Ask。
4. 输入消息并发送；流式过程中可随时停止。

## Ask / Agent 与规划

- Ask：只聊天和分析，不自主访问本地资源。
- Plan：作为 Desktop Agent 的内部只读规划阶段，不是常驻一级模式。
- Agent：可以按权限规则执行工具、修改文件和运行命令。

Web 不显示 Agent、Plan、本地工作区或 MCP。Desktop 的工作区入口位于输入区附近；普通问答不要求先选择工作区。

## 个性化

当前设置页可配置称呼、回复语言、详细程度、表达风格和自定义指令。`USER.md`、`PERSONA.md`、`INSTRUCTIONS.md` 与 `SOUL.md` 高级编辑器尚未开放。所有个性化内容都不能覆盖 Evir 安全和权限规则。

## Skill

Skill 描述完成某类任务的方法。可以启用内置 Skill、导入本地 Skill，或通过 Skill Creator 创建。安装第三方 Skill 前检查它需要的能力和工具。

## MCP（Desktop）

MCP 用于为 Evir 提供外部工具和资源。当前 Desktop 界面只管理本地 stdio 与远程 Streamable HTTP 的配置；保存或启用配置不代表已经连接或可以调用工具。真实连接、工具发现和测试调用闭环仍在开发中。

## 权限和网络

文件写入、终端命令、删除、发布和上传本地内容具有不同风险。网络访问与上传本地数据是两个独立权限。重要操作会要求确认。

## 通知

系统通知能力尚未在当前设置界面开放，也不会在首次启动时请求通知权限。

## 快捷键

使用 `Cmd/Ctrl+N` 新建会话，`Cmd/Ctrl+,` 打开设置，`Cmd/Ctrl+/` 查看快捷键，`Esc` 停止当前生成或关闭最上层弹窗。当前可用列表位于“设置 → 快捷键”；命令面板与快捷键自定义尚未开放。

## Token 与用量

用量页可按时间、供应商和模型查看 Token、请求数和响应性能。供应商返回的数据标记为准确值，本地 tokenizer 计算的数据标记为估算值。

## 数据与隐私

Evir 数据默认留在本地。API Key 存入系统安全凭据库。隐私会话不会写入长期聊天、记忆和用量记录，但模型请求仍受所选供应商的数据政策约束。

## 故障排查

- Web 无法连接但 Key 正确：检查 CORS，或改用 Desktop。
- Agent 模式不可用：检查模型是否支持 Tool Calling。
- MCP：当前构建只保存配置，不能将“配置已启用”视为连接成功。
- 响应中断：保留已生成内容后重试，并检查供应商状态页。

## 提交反馈

当前应用内尚无反馈表单。可手动前往项目 GitHub Issues 提交问题；不要提交 API Key、私密对话或敏感文件内容。

## 切换模型

空闲时可直接切换。正在生成时默认下一条消息生效；也可先停止。Agent 正在执行工具时，Evir 会等待安全步骤边界并生成任务交接摘要。跨供应商切换会提示后续数据将发送到新的服务。

## 上下文压缩

Evir 会在长会话接近模型上下文上限时自动整理旧对话和工具输出。用户要求、权限、当前任务、文件变更和验证结果会优先保留。默认不要求额外配置一个压缩模型。

## 日志与诊断

“设置 → 诊断”可查看当前会话内存中的脱敏运行事件，并导出 JSON。文件日志、日志目录、临时详细日志和离线诊断 ZIP 尚未实现，不能把当前导出当成完整诊断包。
