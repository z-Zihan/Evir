# Evir 使用帮助

## 快速开始

1. 打开“设置 → 模型供应商”。
2. 选择厂商、协议和模型，填写自己的 API Key。
3. 测试连接后返回聊天页，选择 Ask、Plan 或 Agent 模式。
4. 输入消息并发送；流式过程中可随时停止。

## Ask / Plan / Agent

- Ask：只聊天和分析，不自主访问本地资源。
- Plan：可以使用已授权的只读信息制定计划，不修改文件。
- Agent：可以按权限规则执行工具、修改文件和运行命令。

## 个性化

设置页的简单模式适合配置称呼、语言、回答风格和长期偏好。高级模式支持 `USER.md`、`PERSONA.md`、`INSTRUCTIONS.md` 和 `SOUL.md`。这些内容不能覆盖 Evir 安全和权限规则。

## Skill

Skill 描述完成某类任务的方法。可以启用内置 Skill、导入本地 Skill，或通过 Skill Creator 创建。安装第三方 Skill 前检查它需要的能力和工具。

## MCP（Desktop）

MCP 为 Evir 提供外部工具和资源。Desktop 支持本地 stdio 与远程 Streamable HTTP。新增 MCP 后先测试连接、检查工具列表，再启用。不要向不可信 MCP 提供敏感环境变量。

## 权限和网络

文件写入、终端命令、删除、发布和上传本地内容具有不同风险。网络访问与上传本地数据是两个独立权限。重要操作会要求确认。

## 通知

系统通知默认关闭。在“设置 → 通知”开启后，Evir 可在长任务完成、等待审批或失败时提醒。通知默认不显示敏感内容。

## 快捷键

使用 `Cmd/Ctrl+K` 打开命令面板，`Cmd/Ctrl+N` 新建会话，`Cmd/Ctrl+,` 打开设置，`Esc` 停止当前生成或关闭弹窗。完整列表和自定义入口位于“设置 → 快捷键”。

## Token 与用量

用量页可按时间、供应商和模型查看 Token、请求数和响应性能。供应商返回的数据标记为准确值，本地 tokenizer 计算的数据标记为估算值。

## 数据与隐私

Evir 数据默认留在本地。API Key 存入系统安全凭据库。隐私会话不会写入长期聊天、记忆和用量记录，但模型请求仍受所选供应商的数据政策约束。

## 故障排查

- Web 无法连接但 Key 正确：检查 CORS，或改用 Desktop。
- Agent 模式不可用：检查模型是否支持 Tool Calling。
- MCP 连接失败：检查命令、工作目录、认证、日志和端口。
- 响应中断：保留已生成内容后重试，并检查供应商状态页。

## 提交反馈

在“设置 → 提交反馈”填写问题，预览将发送的内容，再打开 GitHub Issue。不要提交 API Key、私密对话或敏感文件内容。

## 切换模型

空闲时可直接切换。正在生成时默认下一条消息生效；也可先停止。Agent 正在执行工具时，Evir 会等待安全步骤边界并生成任务交接摘要。跨供应商切换会提示后续数据将发送到新的服务。

## 上下文压缩

Evir 会在长会话接近模型上下文上限时自动整理旧对话和工具输出。用户要求、权限、当前任务、文件变更和验证结果会优先保留。默认不要求额外配置一个压缩模型。

## 日志与诊断

在“设置 → 数据与隐私 / 关于 Evir”中可以打开日志目录、开启临时详细日志或导出诊断包。日志默认脱敏且只保存在本地。提交 GitHub Issue 前请预览诊断包，不要上传敏感会话或文件内容。
